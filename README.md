## 关于这个仓库

这里只放**课程内容、练习素材和工程文件**。
本机的安装路径、账号、示例目录等环境信息**不写进仓库**，统一放在本地文件 `CLAUDE.local.md`（已被 `.gitignore` 忽略）。

课程基于 **Spine 4.3** 编写，界面使用简体中文。

中文界面很好上手，但**网上 99% 的教程和论坛都是英文**。
所以我们的约定是：**界面用中文操作，术语一定记英文**（见 `术语表.md`）。
两边对上号，你就既看得懂界面，也看得懂教程。

## 文件夹是干什么的

```
D:\a_geren\spine\
├─ README.md                 ← 你正在看的说明
├─ 00-学习路线图.md           ← 20 节课的完整路线 + 进度表
├─ 01-第1课-认识Spine.md      ← 每节课一个文件，跟着做就行
├─ 术语表.md                  ← 中英对照，随时查
├─ 笔记\                      ← 你自己的笔记、截图、问题
├─ 练习\
│  ├─ _工具\make_parts.py     ← 生成练习素材的脚本（不用管它）
│  └─ 01-方块小哥\parts\      ← 我生成的第一套练习素材
└─ 项目\
   └─ 方块小哥\
      ├─ images\              ← 素材已经放好了，Spine 会自动找到
      └─ (你保存的 .spine 工程会出现在这里)
```

**为什么要按这个结构放？** Spine 的工程习惯是：`.spine` 文件旁边放一个 `images` 文件夹。
Spine 会记住这个相对路径，换电脑、发给同事都不会丢图。

## 每天怎么学（建议 30~60 分钟）

1. **读**：打开当天的课程文件，先看 5 分钟"为什么"。
2. **做**：跟着步骤在 Spine 里操作，**不要只看不动手**。
3. **卡**：卡住超过 10 分钟就来问我，把"你点了什么 / 看到什么"描述清楚。
4. **记**：在 `笔记\` 里写 3 行：今天学了什么、哪里卡了、明天要做什么。

学习动画软件最大的坑不是难，是**只看不做**。手比眼慢，是正常的。

## 怎么向我提问最有效

直接说人话就行，例如：

- "我按 Ctrl+Tab 切不到动画模式，按钮是灰的"
- "我把图片拖进视口了，但是图跑到左下角去了"
- "第 4 课的这一步我找不到，截图给你"（截图可以直接拖进这个窗口）

我会先问清楚你点的是哪里，再给下一步。**不要怕问基础问题**，零基础就是用来问的。
